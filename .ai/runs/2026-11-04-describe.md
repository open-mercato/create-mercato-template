## Goal

Ship Step 10 of the spec's Implementation Plan: `describe --from <dir>` prints the catalog entry YAML for `templates/<owner>/<repo>.yml` from the report, the manifest and the repo, with the CONTRIBUTING link, offline and read-only.

## Scope

- `src/describe.ts`: read `<dir>/report.json` (missing or with error findings: exit 1), the manifest in `<dir>/tree/mercato-template.json`, the repo from `<dir>/publication.json` or `--repo` (both and different: exit 2; neither: exit 2); build the entry (`github`, `useCase`, `summary`, `whenToUse`, `whenNotToUse`, `pricing: free`, `declares.env`), lower-cased path and `github`, placeholders for missing required values with `complete: false` and `missing`, the CONTRIBUTING link; never a curator field, `smoke` or a `/submit` link.
- `src/cli.ts`: `describe` dispatched with `--from`, `--repo`, `--use-case`, `--summary`, `--when-to-use`, `--when-not-to-use`, `--json`; value checks (exit 2); envelope fields `path`, `yaml`, `entry`, `complete`, `missing`, `contributing`.
- `test/fixtures/catalog/template-1.json`: draft written from the catalog spec and `lib/schema/descriptor.ts`/`common.ts` at open-mercato/modules 5a591d6, marked as a draft like `mercato-template-1.json`; `SOURCE.md` updated.
- Tests: `test/describe.test.cjs` with every case named under Step 10.
- Docs: `docs/guide.md`, `--help`, `CHANGELOG.md` (Unreleased), `AGENTS.md` status and routing, README status line.

## Non-goals

- Step 11 and later: no release-checks job, no release.
- No change to `prepare`, `publish`, the report schema or the `snapshotId` algorithm.

## Risks

- A secret, token or email in the output: the YAML takes only flag text checked as plain text, the manifest description checked as plain text, env key names with their manifest descriptions and links, and the repo name. Tests scan the output.
- The vendored `template-1.json` is a guess until the catalog publishes it; every guess is listed in `SOURCE.md` and the PR body.
